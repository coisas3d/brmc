# Black Rock MC - The Game

Corrida de motos em pixel art feita pela **Coisas 3D** para os membros do Black Rock Moto Clube (Itaúna - MG). Projeto sem fins lucrativos.

- Jogar: https://coisas3d.github.io/brmc/
- `servidor/worker.js`: ranking global (Cloudflare Worker), grava o `ranking.json` deste repositório.
